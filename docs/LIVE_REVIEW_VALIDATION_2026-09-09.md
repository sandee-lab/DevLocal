# Grok 실제 호출 검증 결과

2026-09-09, 코드 리뷰 수정사항의 후속 검증.

| 항목 | 결과 |
|---|---|
| 요청 모델 / 응답 모델 | `xai/grok-4.6` / `grok-4.6` |
| 설정 | `reasoning_effort=low`, timeout 120초 |
| 실제 호출 | 9회, 전부 성공 |
| 소요 시간 | 121.85초 |
| 한국어 검수 | 합성 문장 50행, 1개 청크, 응답 누락 없음 |
| 번역·검수 | 한국어 검수 결과 중 10행 × EN·JA·ZH-CN·ZH-TW = 40건 |
| 기능 검증 | 18개 항목 통과 |
| 입력 / 출력 / reasoning / cached 토큰 | 15,906 / 8,430 / 2,678 / 5,888 |
| 프로젝트 설정 단가로 계산한 추정 비용 | $0.0896 |

한국어 50행에는 중복 Key, 명백한 맞춤법 오류, 변경할 필요가 없는 문장, 변수, 색상·볼드 태그, printf 지정자, 리터럴 `\n`·`\t`를 포함했다. 한국어 검수에서 생성한 실제 결과 중 10행을 다음 LangGraph 실행에 캐시로 주입하여 동일한 검수 요청을 반복하지 않았다.

## 확인한 수정사항

- 한국어 검수에서 변경 없는 행을 포함한 50행이 모두 반환됐다.
- 중복 Key의 원문이 행 번호별로 구분됐고 교정 후에도 태그를 유지했다.
- 실제 교정 제안 중 한 항목을 거부했을 때 Translator·Reviewer가 해당 원문을 유지했다.
- 네 언어의 40개 행·언어 조합이 누락·중복 없이 최종 승인 대기에 도달했다.
- 번역문에 태그 손상·한글 잔존·실제 개행/탭 혼입이 없었다.
- AI 검수 응답 누락이나 호출 오류가 없었다.
- 최종 승인에서 거부한 영어 셀은 업데이트 목록에 포함되지 않았다.
- 선택 범위의 첫 행이 시트 9행에 대응하도록 구성한 테스트에서 모든 업데이트가 9~18행에만 배치됐다.
- 동일한 최종 승인 요청을 다시 보내도 준비된 Batch 쓰기는 한 번만 실행됐다.

## AI 품질 경고 2건

기능 검증 통과가 모든 번역의 의미 정확성을 보증하지는 않는다. 실제 Reviewer가 다음 경고를 반환했고, 기존 동작대로 결과의 `reason`에 표시됐다.

| 항목 | 번역 | Reviewer 경고 |
|---|---|---|
| 일본어, 체력 회복 안내 | `体力が{hp}ぶん回復したよ。` | 원문의 현재형 안내와 번역의 과거형 시제가 다름 |
| 중국어 간체, 다음 레벨 진행도 | `距下一级还有 {exp}/{max}` | `还有`가 진행도를 잔여량으로 해석하게 할 수 있음 |

## 범위와 한계

Grok 호출과 LangGraph 실행은 실제였다. Google Sheets 객체와 백업 저장은 mock으로 대체했다. 따라서 실제 시트 반영·네트워크 쓰기 재시도·브라우저 E2E를 검증한 것은 아니다. 배포·커밋·푸시는 하지 않았다.

합성 문장에 대한 한 차례 실행이므로 실제 게임 시트 전체의 번역 품질·대규모 부하를 대표하지 않는다. 비용은 API 응답 토큰과 현재 프로젝트 단가로 계산한 추정치다.

재현 스크립트: `scripts/verify_live_review.py` — 실행하면 유료 API 호출이 발생한다. 호출 상한은 20회이며 이번 실행은 9회였다.

상세 호출 시간·토큰·교정문·번역문·검증 결과: `docs/live-review-validation.json`.
